## Event Schema

Every event generated by the engine adheres to this standard schema:

```json
{
  "id": "ev_1727613600000_abc12",
  "type": "SUPPORT_MEDIUM",
  "amount": 100,
  "currency": "INR",
  "source": "demo",
  "displayName": "Pooja M.",
  "timestamp": "2026-09-29T15:10:00.000Z",
  "status": "verified",
  "metadata": {
    "paymentId": "demo_pay_12345",
    "transactionRef": "tx_demo_67890"
  }
}
```

## Realtime Voice & Personality State

In addition to financial and sponsor state, the event engine projects safe, sanitised voice state to the frontend HUD and SSE subscribers:

```json
{
  "isSpeaking": false,
  "isVoiceMuted": false,
  "voiceStatus": "ready",
  "lastVoiceLine": "Arre wah! ₹50 aa gaya!"
}
```

Zero internal TTS credentials, API keys, or provider endpoints are ever exposed.
